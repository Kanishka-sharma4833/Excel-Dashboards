# Vrinda Store Annual Report 2022

An interactive *Excel Dashboard* designed to analyze Vrinda Store's sales and order data and provide meaningful business insights into sales performance, customer demographics, order status, and sales channels.

## Key Highlights

- Overall sales and order analysis
- Monthly sales and order analysis
- Order vs sales comparison
- Top 5 states by sales
- Men vs women sales analysis
- Age-wise customer analysis
- Gender-wise customer analysis
- Order status analysis
- Sales channel analysis
- Category-wise sales analysis
- Interactive filtering using month, category, and channel

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization
- Interactive Dashboard

## Dashboard Insights

- Analyzed monthly sales and order trends
- Identified top-performing states
- Compared sales contribution between men and women
- Analyzed customer age groups and gender
- Examined order status such as delivered, cancelled, and refunded
- Compared orders across different sales channels
- Created an interactive dashboard for easy business analysis
