# Swiggy Sales Analysis Dashboard

An interactive **Excel Dashboard** designed to analyze Swiggy food delivery data and provide meaningful insights into sales performance, customer orders, ratings, food preferences, and city-wise performance.

## Key Highlights

- Overall sales and order analysis
- Monthly sales trend analysis
- Daily sales trend analysis
- Weekly sales trend analysis
- Top 5 cities by sales
- Sales by food type
- Sales by state analysis
- Total sales, orders, and rating analysis
- Average order value analysis
- Quarterly sales and order analysis
- Restaurant-wise analysis
- Category-wise analysis
- Interactive filtering using month, category, and restaurant

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Maps
- Data Cleaning
- Data Analysis
- Data Visualization
- Interactive Dashboard

## Dashboard Insights

- Analyzed monthly, weekly, and daily sales trends
- Identified top-performing cities by sales
- Compared sales between different food types
- Analyzed state-wise sales performance
- Evaluated quarterly sales, ratings, and order volume
- Analyzed restaurant and category performance
- Created an interactive dashboard for business analysis
