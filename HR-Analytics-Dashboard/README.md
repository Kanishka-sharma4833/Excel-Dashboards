# HR Analytics Dashboard

An interactive Excel dashboard designed to analyze workforce data and provide meaningful insights into employee headcount, attrition, diversity, job levels, and employee stability.

## Key Highlights

- Overall headcount analysis
- Active employee and attrition analysis
- Attrition rate analysis
- Headcount growth analysis
- Gender diversity analysis
- Job level distribution
- Department-wise headcount analysis
- Employee type analysis
- Employee stability analysis
- Employee reporting analysis
- Interactive filtering using department and employee

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Analysis
