# Road Accident Dashboard

An interactive **Excel Dashboard** designed to analyze road accident data and provide meaningful insights into casualties, accident trends, vehicle types, road conditions, locations, and accident severity.

## Key Highlights

- Overall casualty analysis
- Fatal, serious, and slight casualty analysis
- Monthly casualty trend analysis
- Casualties by vehicle type
- Casualties by road type
- Casualties by road surface
- Casualties by location
- Casualties by light condition
- Casualties by car
- Urban vs Rural casualty analysis
- Year-wise accident analysis
- Interactive accident date filtering
- Interactive filtering using accident date and location

## Dashboard KPIs

- Total Casualties: 417,883
- Fatal Casualties: 7,135
- Serious Casualties: 59,312
- Slight Casualties: 351,436
- Casualties by Car: 33,348
